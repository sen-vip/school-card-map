# 🗺️ 학교카드맵

서울특별시교육청 업무추진비 공개자료를 불러와
학교카드 사용처를 표와 지도에서 한눈에 확인할 수 있는 웹 도구입니다.

### [학교카드맵 바로가기](https://school-card-map.vercel.app/)

> 서울특별시교육청 소속 학교만 지원합니다. 열린서울교육 업무추진비 공개자료를 기준으로 작동하므로 다른 시·도 학교는 조회할 수 없습니다.

---

## ✨ 주요 기능

* 학교명과 기준월을 입력하여 업무추진비 공개자료 자동 수집
* 수집한 집행 내역 자동 정리
* 학교 주소를 기준으로 검색 지역 자동 확인
* 카카오맵 기반 학교카드 사용처 지도 표시
* 데스크톱과 모바일 모두 지도를 먼저 보여주는 지도 중심 결과 화면
* 같은 장소에서 여러 번 사용한 내역 묶어서 표시
* 장소별 집행일자, 금액, 집행목적 확인
* 지도 표시, 지도 제외, 위치 확인 필요 내역 분류
* 네이비·블루 기반의 밝고 안정적인 반응형 UI
* 검색 결과가 정확하지 않은 장소의 위치 직접 수정
* 모바일 카드형 결과 목록과 기준월 입력 최적화 지원
* 학교명 입력창에 서울 소재 학교명 입력 안내 제공
* 공개 내역 없음·학교 확인 필요·자료 연결 오류 상태를 구분하여 안내
* 공개자료를 직접 붙여넣는 수동 입력 방식 지원

---

## 🚀 사용 방법

1. [학교카드맵](https://school-card-map.vercel.app/)에 접속합니다.
2. 조회할 학교명을 입력합니다.
3. 기준월을 선택합니다.
4. `사용처 지도 만들기`를 누릅니다.
5. 먼저 표시되는 지도에서 사용처 위치를 확인하고, 아래 또는 오른쪽 목록에서 세부 내역을 확인합니다.
6. 위치가 정확하지 않은 장소는 `위치 수정`을 눌러 직접 보정합니다.

기준월은 공개자료 등록 시점을 고려하여 기본적으로 지난달이 선택됩니다.

---

## ℹ️ 조회 결과 안내

조회가 완료되었지만 자료가 없는 경우를 앱 오류와 구분하여 안내합니다.

* **공개 내역 없음**: 학교는 확인됐지만 해당 기준월에 승인·공개된 업무추진비 자료가 없는 경우
* **학교 확인 필요**: 서울 소재 학교로 확인되지 않는 경우
* **자료 연결 오류**: 열린서울교육 연결이나 응답 처리에 문제가 생긴 경우

공개 내역이 없는 경우에는 다른 기준월을 선택할 수 있고, 연결 오류가 발생하면 입력값을 유지한 채 다시 시도할 수 있습니다.

## 📍 위치 검색 방식

학교명만으로 자치구를 추정하지 않고 학교 주소 조회 결과를 활용합니다.

위치 검색은 다음 순서로 진행됩니다.

1. 사용자가 입력한 지역 보조어 확인
2. 학교 주소 조회 결과에서 서울특별시 자치구 확인
3. 카카오 장소검색을 이용한 학교 위치 보조 확인
4. 주소 확인 실패 시 서울특별시 전체 범위 검색

사용처 검색은 식당명과 지점명 일치를 우선하며, 학교가 위치한 자치구는 검색 결과를 판단하기 위한 보조 정보로 활용합니다.

## 🗂️ 프로젝트 구조

```text
school-card-map/
├─ api/
│  ├─ sen_fetch.py       # 서울교육청 공개자료 수집 API
│  └─ school_info.py     # 학교 주소 조회 API
├─ app.js                # 화면 기능
├─ index.html            # 메인 화면
├─ styles.css            # 화면 디자인
├─ server.py             # 로컬 실행용 서버
├─ vercel.json           # Vercel 경로 연결 설정
└─ README.md
```

프론트 화면에서는 `/sen-fetch`로 업무추진비 자료를 요청합니다.

Vercel에서는 `vercel.json`을 이용하여 해당 요청을 `/api/sen_fetch`로 연결하며, 학교 주소는 `/api/school_info`에서 조회합니다.

## 🌐 Vercel 배포

### GitHub 저장소에 올리기

```bash
git add .
git commit -m "Update school card map"

```

### Vercel에서 배포하기

1. Vercel에 접속합니다.
2. GitHub 계정으로 로그인합니다.
3. `Add New` → `Project`를 선택합니다.
4. `school-card-map` 저장소를 선택합니다.
5. Framework Preset은 `Other`를 선택합니다.
6. 별도의 Build Command 없이 배포합니다.

배포 주소:

```text
https://school-card-map.vercel.app/
```

GitHub 저장소에 새로운 내용을 올리면 연결된 Vercel 프로젝트에 자동으로 다시 배포됩니다.


## 🔑 카카오 지도 설정

일반 사용자는 별도의 지도 키를 입력하지 않고 사용할 수 있습니다.

프로젝트를 포크하거나 다른 도메인에 다시 배포하는 경우에는 카카오 개발자 콘솔의 JavaScript SDK 도메인에 배포 주소를 등록해야 합니다.

```text
https://school-card-map.vercel.app
```

GitHub Pages 주소도 함께 사용하는 경우 다음 도메인을 추가할 수 있습니다.

```text
https://sen-vip.github.io
```

앱의 `지도 고급 설정`에서 직접 입력한 JavaScript 키는 브라우저의 로컬 저장소에만 저장됩니다.

> Admin 키 또는 REST API 키는 코드에 넣지 마세요.
> 이 프로젝트에는 카카오 JavaScript 키만 사용합니다.

---

## 🤔 Vercel을 사용하는 이유

GitHub Pages는 정적 웹페이지를 배포할 수 있지만, 공개자료 수집에 필요한 Python API를 실행할 수 없습니다.

따라서 학교카드맵은 서버리스 API를 사용할 수 있는 Vercel에 배포합니다.
